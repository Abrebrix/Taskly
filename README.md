## 🚀 Как скомпилировать SCSS

В проекте используются стили на SCSS. Браузеры не понимают SCSS напрямую, поэтому его нужно скомпилировать в CSS.

### 1. Если не установлен, установить node.js, проверить можно командой node -v
### 2. После установки node необходимо устоновить sass, для этого используйте: npm install -g sass
### 3. После устоновки sass необходимо скомпилировать scss для этого выполните команду: sass ./scss/main.scss ./css/main.css --no-source-map
### 4. Готово!
