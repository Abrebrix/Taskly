## 🚀 Как скомпилировать SCSS

В проекте используются стили на SCSS. Браузеры не понимают SCSS напрямую, поэтому его нужно скомпилировать в CSS.

### Если вы используете VS Code
1. Установите расширение **Live Sass Compiler** в VS Code.
2. Откройте любой `.scss` файл.
3. Нажмите кнопку **«Watch Sass»** в нижней панели VS Code.
4. Готовый CSS появится в папке `css/`.
