## 🚀 Как скомпилировать проект

В проекте используются TypeScript и Sass. Для их компиляции выполните следующие шаги:

### 1. Установите Node.js
Если он еще не установлен, скачайте и установите [Node.js](https://nodejs.org/). Проверить установку можно командой в терминале:
`node -v`

### 2. Установите зависимости
Откройте терминал в корневой папке проекта и выполните команду:
`npm install`

### 3. Скомпилируйте проект
Чтобы собрать стили и скрипты один раз, выполните команду:
`npm run build`

*(Если вы планируете вносить изменения в код и хотите, чтобы проект пересобирался автоматически при каждом сохранении файла, используйте команду `npm run watch`)*.

### 4. Готово! 
Скомпилированные файлы появятся в папке `build`.
